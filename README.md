**TradeMind AI** is a professional-grade, full-stack stock market analysis and simulation platform. Built with a modern fintech aesthetic, it combines real-time market data, AI-driven price predictions, and robust portfolio management into a single, seamless experience.

---

## 🏗️ Architectural Overview

The platform is designed with a decoupled architecture for maximum scalability:
- **Frontend**: A high-performance Next.js application using the App Router and Turbopack.
- **Real-time Data**: Integrated with **Yahoo Finance** for live market quotes and historical trends.
- **Intelligence Layer**: A Python-based ML microservice (FastAPI) running **LSTM Neural Networks** for price forecasting.
- **Persistence**: Type-safe data management via **Prisma ORM** with a localized SQLite engine for instant setup.
- **Payments**: Integrated **Razorpay** SDK for simulated wallet deposits.

## ✨ Key Features

### 📈 Real-Time Market Intelligence
- **Live Tracking**: Monitor Nifty 50, Sensex, and individual stocks with sub-second accuracy.
- **Advanced Search**: Instantly find Indian (NSE/BSE) and Global stocks.
- **Interactive Charts**: Performance visualization powered by **Recharts** with glassmorphic styling.

### 🧠 AI Price Forecasting
- **LSTM Predictions**: 7-day future price outlook generated by recurrent neural networks.
- **Confidence Scoring**: Model-derived confidence metrics for informed decision-making.

### 💼 Portfolio & Wealth Management
- **Live P/L Tracking**: Real-time calculation of Profit/Loss and investment returns.
- **Simulated Trading**: Execute Buy/Sell orders with live market prices.
- **Digital Wallet**: Manage funds with Razorpay integration and detailed transaction history.
- **Asset Allocation**: Visual breakdown of your holdings via dynamic pie charts.

### 🎓 Learning & News
- **Learning Center**: Comprehensive modules covering Basics, Technical Analysis, and Risk Management.
- **Smart News Feed**: Aggregated financial news curated specifically for the stock market.

## 🚀 Getting Started

### Prerequisites
- **Node.js**: v20.9 or higher (recommended for Next.js 16)
- **npm** or **yarn**
- **Python**: 3.9+ (Mandatory for AI features)

### 1. Installation
```bash
# Clone the repository
git clone https://github.com/HarshitChand5/Stock-Market-Project.git
cd Stock-Market-Project

# Install dependencies
npm install --legacy-peer-deps
```

### 2. Environment Configuration
Create a `.env` file in the root directory:
```env
# Auth
NEXTAUTH_SECRET=your_secret_here
NEXTAUTH_URL=http://localhost:3000

# Database
DATABASE_URL="file:./dev.db"

# APIs
NEWS_API_KEY=your_newsapi_key
ML_SERVICE_URL=http://localhost:8000

# Optional: Razorpay wallet deposits
RAZORPAY_KEY_ID=your_razorpay_key_id
RAZORPAY_KEY_SECRET=your_razorpay_key_secret
NEXT_PUBLIC_RAZORPAY_KEY_ID=your_razorpay_key_id

# Optional: Google sign-in
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
```

### 3. Database Initialization
The Prisma schema in this repository uses SQLite. The `file:./dev.db` URL is resolved relative to `prisma/schema.prisma`, so the database file is created under `prisma/`.

```bash
npx prisma generate
npx prisma db push
```

If you do not have API credentials yet, leave the optional keys blank. Core pages may run, but news, Google sign-in, and Razorpay wallet deposits will require their respective credentials. The ML service currently returns demo/mock predictions; its source comments describe the intended future trained-model integration.

### 4. Running the Project
```bash
# Terminal 1: Frontend & API
npm run dev

# Terminal 2: AI Microservice
cd ml-service
python -m venv .venv
# Windows PowerShell:
.venv\\Scripts\\Activate.ps1
# Windows Command Prompt instead:
# .venv\\Scripts\\activate.bat
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

---

For the frontend, open http://localhost:3000. The ML API docs are available at http://localhost:8000/docs when the Python service is running.

> Note: `docker-compose.yml` currently defines PostgreSQL, while `prisma/schema.prisma` is configured for SQLite. Use the local setup above unless you intentionally reconcile those configurations before using Docker Compose.

## 📂 Project Structure

- `src/app`: Application routes and page logic.
- `src/components`: Reusable UI elements and layout components.
- `src/lib`: Shared utilities, Prisma client, and mock data.
- `src/api`: Backend API endpoints for trades, wallet, and market data.
- `ml-service`: Python FastAPI implementation for AI models.
- `prisma`: Database schema definitions.
